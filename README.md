# 🎯 Dart Course - Основи програмування на Dart

Курс з вивчення основ мови програмування Dart. Проєкт містить практичні приклади, домашні завдання та рішення для кожного уроку.

## 📚 Структура курсу

### Урок 4: Змінні та типи даних
- Основні типи даних: `int`, `double`, `String`, `bool`
- Колекції: `List`, `Set`, `Map`
- Спеціальні типи: `dynamic`, `var`
- Оголошення та використання змінних

**Файли:**
- `lib/lesson_05/main.dart` - основні приклади
- `lib/lesson_05/variables.dart` - робота зі змінними
- `lib/lesson_05/materials/homework.md` - домашнє завдання

### Урок 5: Оператори та керуючі конструкції 
- Математичні оператори
- Оператори порівняння та логічні оператори
- Тернарний оператор
- Умовні конструкції: `if-else`, `if-case`, `switch`
- Цикли: `for`, `while`, `do-while`
- `break`, `continue`, `return`

**Файли:**
- `lib/lesson_06/main.dart` - основні приклади
- `lib/lesson_06/homework/` - домашнє завдання

### Урок 6: Функції та області видимост
- Основи функцій
- Типи параметрів: позиційні, іменовані, опціональні
- Значення за замовчуванням
- Повернення значень
- Стрілочні функції
- Область видимості змінних
- Найкращі практики

**Файли:**
- `lib/lesson_07/main.dart` - основні приклади

### Урок 7: Колекції та робота з даними
- Створення та робота з картами
- Особливості карт (унікальність ключів)
- Ітерація по картах
- Зміна карт (додавання, видалення, оновлення)
- Корисні методи роботи з картами
- Операції з картами (об'єднання, перевірка)
- Практичні приклади використання

**Файли:**
- `lib/lesson_08/main.dart` - основні приклади
- `lib/lesson_08/homework/` - домашнє завдання та рішення

## 🚀 Як запустити

### Вимоги
- Dart SDK версії 3.2.5 або вище

### Запуск прикладів

Для запуску прикладів з конкретного уроку:

```bash
# Урок 5
dart run lib/lesson_05/main.dart

# Урок 6
dart run lib/lesson_06/main.dart

# Урок 7
dart run lib/lesson_07/main.dart

# Урок 8
dart run lib/lesson_08/main.dart
```
