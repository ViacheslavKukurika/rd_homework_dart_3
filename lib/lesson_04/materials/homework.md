# Домашнє завдання - Урок 1: Типи даних та змінні

## Завдання 1: Інформація про студента
Створіть програму, яка зберігає та виводить інформацію про студента:
- Ім'я (String)
- Прізвище (String) 
- Вік (int)
- Середній бал (double)
- Чи навчається (bool)

## Завдання 2: Колекції
Створіть та заповніть:
- List з 5 улюблених предметів
- Set з унікальними оцінками (1-12)
- Map з предметами та їх оцінками

## Завдання 3: Експерименти з типами
- Створіть dynamic змінну, змініть її тип 3 рази
- Створіть var змінну та спробуйте змінити тип (що станеться?)
- Використайте final для незмінної змінної
- Використайте const для константи

## Завдання 4: Виведення
Створіть красивий вивід інформації про студента:
1. Використайте print() для виведення кожного поля окремо
2. Додайте заголовок "=== Інформація про студента ==="
3. Для bool значення виведіть "Навчається" або "Не навчається"
4. Для List та Map використайте інтерполяцію рядків ($змінна)
5. Додайте порожні рядки між блоками інформації для кращої читабельності

Приклад виводу:
```
=== Інформація про студента ===

Особисті дані:
Ім'я: Іван Петренко
Вік: 20 років

Навчання:
Статус: Навчається
Середній бал: 10.5

Предмети: [Математика, Фізика, Програмування]
Оцінки: {Математика: 11, Фізика: 10, Програмування: 12}
```
