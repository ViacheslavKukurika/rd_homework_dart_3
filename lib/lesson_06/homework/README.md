# Домашнє завдання - Урок 6

## Завдання 1: Калькулятор оцінок
Створіть програму, яка:
- Приймає оцінку студента (0-100)
- Використовуючи if-else, визначає літерну оцінку:
  - A: 90-100
  - B: 80-89
  - C: 70-79
  - D: 60-69
  - F: 0-59

## Завдання 2: Аналіз числа з if-case
Використовуючи if-case pattern matching, створіть функцію, яка аналізує число та виводить:
- Чи число парне/непарне
- Чи число позитивне/негативне/нуль
- Чи число в діапазоні 1-10

## Завдання 3: Switch для днів тижня
Створіть switch expression, який:
- Приймає день тижня
- Повертає кількість годин роботи для цього дня
- Понеділок-п'ятниця: 8 годин
- Субота: 4 години
- Неділя: 0 годин

## Завдання 4: Цикли та умови
Напишіть програму, яка:
- Використовує цикл for від 1 до 20
- Пропускає числа, що діляться на 3 (continue)
- Зупиняється на числі 15 (break)
- Виводить тільки парні числа

## Завдання 5: Логічні оператори
Створіть функцію для перевірки доступу до системи:
- Користувач має бути авторизований
- Вік >= 18 АБО має дозвіл батьків
- Система має бути онлайн
- Виведіть результат перевірки з поясненням
