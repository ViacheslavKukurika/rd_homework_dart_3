# Домашнє завдання - Урок 8: Карти (Map)

## Завдання 1: Телефонна книга
Створіть програму, яка:
- Створює карту контактів (ім'я -> номер телефону)
- Додає 5 контактів
- Знаходить номер за ім'ям
- Перевіряє чи існує контакт
- Виводить всі контакти

## Завдання 2: Інвентар магазину
Створіть карту товарів (назва -> кількість):
- Додайте 6 товарів з різною кількістю
- Знайдіть товари з кількістю > 10
- Оновіть кількість товару (продаж)
- Додайте новий товар
- Видаліть товари з кількістю 0

## Завдання 3: Оцінки студентів
Створіть карту студентів (ім'я -> список оцінок):
- Додайте 4 студента з оцінками
- Обчисліть середню оцінку для кожного
- Знайдіть студента з найвищою середньою оцінкою
- Додайте нову оцінку студенту

## Завдання 4: Статистика слів
Напишіть програму, яка:
- Приймає текст (рядок)
- Підраховує кількість кожного слова
- Виводить слова за частотою використання
- Знаходить найчастіше слово

## Завдання 5: Конвертер валют
Створіть карту курсів валют (валюта -> курс до гривні):
- Додайте 5 валют з курсами
- Створіть функцію конвертації з однієї валюти в іншу
- Оновіть курс валюти
- Виведіть всі доступні валюти

## Завдання 6: Групування даних
Створіть список людей з віком та згрупуйте їх:
- За віковими категоріями (дитина: 0-12, підліток: 13-17, дорослий: 18+)
- Використайте карту для групування
- Виведіть кількість людей в кожній групі
